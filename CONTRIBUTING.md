# Contributing to RagLeap Core

Thanks for your interest in contributing! Here's the honest current state and how to help.

## Where things stand

RagLeap Core is in an early extraction phase — we're pulling a clean, standalone core engine out of RagLeap's larger production codebase. See [ROADMAP.md](ROADMAP.md) for the current phase.

Because of this, the most valuable contributions right now are:

- **Feedback on direction** — open a [Discussion](../../discussions) if you have thoughts on architecture, scope, or what you'd want from a self-hosted RAG engine
- **Documentation** — improvements to setup instructions, architecture explanations, or examples
- **Testing** — trying the setup once it's published and reporting what breaks

Code contributions to the core engine itself will open up once Phase 2 (core extraction) is further along — watch the repo or check the Roadmap for updates.

## Reporting bugs

Open an [Issue](../../issues) with:
- What you expected to happen
- What actually happened
- Steps to reproduce
- Your environment (OS, Docker version, etc.)

## Code style

Once the core is published: Python (PEP 8), clear commit messages, small focused pull requests over large ones.

## Code of Conduct

Be respectful and constructive. Full Code of Conduct coming soon.

## Questions

Open a [Discussion](../../discussions) or reach out via [ragleap.com](https://ragleap.com).
